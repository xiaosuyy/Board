当前主要功能
------------
1. 顶部动态面板：TOOLBAR / CANDIDATES / MORE / CLIPBOARD 四状态共用 56dp 高度
   （收起键盘键在剪贴板图标左侧，调用 requestHideSelf，不模拟返回键）
2. 中文输入：librime 朙月拼音 · 简体；单行候选 + 拼音 pill；横向滑动
3. 用户学习：librime userdb 本地学习，选词后候选排序会变化，重启/重装仍在
4. 词库：学习词 / 自定义词 / 固定词 / 屏蔽词 / 常用语；新增、编辑、删除、筛选
5. 词库导入导出：TXT / CSV / JSON / Rime 词库；去重、不覆盖、报告条数
6. 剪贴板面板：最近 / 收藏 / 固定 / 删除 / 搜索 / 清空（二次确认）/ 云端筛选
7. 同步：SyncClipboard 协议（SyncClipboard.json）+ 用户自己的 WebDAV
   - 词库 / 学习词 / 常用语各一个实体文件，**合并而不是互相覆盖**
   - 学习词会写回 librime 用户词典 → 真正参与候选排序
   - 删除用 tombstone，另一端不会把删除的条目恢复
   - 同步内容逐项开关；账号密码只在配置阶段展示
8. 设置：首页只放状态 + 8 个一级分类；日志默认隐藏（连点版本号 5 次开启开发者模式）
9. 深色模式、横屏悬浮键盘、按键音效 / 震动

已知限制
--------
- 主题（THEME）/ 键盘设置（KEYBOARD_SETTINGS）只有开关与 SyncEntityType，**尚未实现真正同步**
- 词库类同步采用「一个实体一个文件 + 拉取合并写回」，没有逐条 SyncOperation 任务记录
  （sync_operation 表的 deviceId / deleted / timestamp 字段已就位，目前只有剪贴板推送走队列）
- 学习词同步要求本进程内 Rime 已初始化（打开过一次键盘），否则本次跳过并写日志
- 剪贴板条目的删除还不同步；只有词库类有 tombstone
- 图片 / 文件（Image / File / Group）只识别不传输
- SyncClipboard 协议没有设备字段，设备名来自可选的 device 扩展 / Build.MODEL
- 性能只在模拟器上量过帧率（四组场景 0 janky），真机只做了功能验证
- 未在商业 WebDAV（Nextcloud 等）上验证，测试用的是 tools/test_webdav.ps1（本机最小实现）

Git 说明
--------
本机（Windows 开发机）**没有预装 git**（PATH、Program Files、ProgramData、scoop 等常见位置
都找不到 git.exe，`where git` 也查不到）。为了完成「提交 + 打标签」的要求，我下载了官方
便携版 **MinGit 2.56.0**（放在临时目录，没有安装到系统里），用它完成了：

    git init
    git add -A
    git commit -m "Board Android mobile stable baseline"   -> d4c5f4a
    git tag -a v0.1.0-mobile -m "Board Android mobile stable baseline"

`.gitignore` 已排除 build/、.gradle/、.kotlin/、.cxx/、local.properties、
third_party/rime/（预编译库用 tools/fetch_rime.ps1 还原）、releases 里的 APK / zip。
仓库本身不依赖那把便携 git，换任何 git 都能正常使用。
